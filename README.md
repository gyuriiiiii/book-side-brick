# React + TypeScript + Vite

학생들이 많이 대출한 도서 목록을 직관적으로 확인할 수 있도록 떨어지는 애니메이션과 3가지 색상, 컨셉(크리스마스)을 적절히 활용한 도서관 미디어월 경진대회 참가작품 입니다.
React, TypeScript 로 기초 디자인과 애니메이션을 구축하고 배경에는 눈 내리는 모습을 구현 했습니다.

주요 기능은 다음과 같습니다.
- Pythpn을 통한 상위 50권의 도서 데이터 추출 (Colab 이용)
- Front-End 개발을 통한 시각화
- 테트리스 게임과 인형뽑기 기계에서 영감을 받아 책 제목이 벽돌처럼 쌓이는 애니메이션
